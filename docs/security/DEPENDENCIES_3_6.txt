CLUB VOID — VULNERABILIDADES Y CLASIFICACIÓN 3.6
Fecha: 10-11-2026

FUENTE Y ALCANCE
npm audit --json y npm audit --omit=dev --json. No se aplicaron correcciones ni se instalaron/actualizaron dependencias.
56 paquetes señalados: 2 críticos, 17 altos, 33 moderados, 4 bajos. No son 56 CVE distintos: el informe incluye severidades heredadas y avisos compartidos.
73 URLs de advisories diferentes en la salida completa.
Solo ejecución: 8 paquetes Angular (4 altos, 4 moderados, 0 críticos). Los otros 48 paquetes están marcados dev en package-lock.
Es una clasificación de exposición basada en código y rutas actuales, no una prueba de ausencia de explotación.

A. EJECUCIÓN — ANGULAR
Angular core 17.3.12, CLI/build 17.3.17. Angular 17 está fuera de soporte según la política oficial consultada.
Riesgo P1 antes de producción: sanear versiones con una migración coordinada Angular/CLI/TypeScript/Node autorizada por el arquitecto. No ejecutar npm audit fix --force. La propuesta automática mezcla familias/versiones y requiere evaluación.
XSS: no se encontraron innerHTML, bypassSecurityTrust, i18n ni SVG script con href dinámico en frontend/src. Las plantillas y las imágenes actuales son locales; no se demostró un vector de explotación de los avisos concretos revisados. Esto no neutraliza todos los advisories de Angular.
HttpTransferCache, hidratación y DoS SSR: no hay SSR/hidratación en esta SPA. Las condiciones de esos avisos no se observan en la arquitectura actual.
XSRF: las URLs HTTP se construyen desde API_URL fija, sin protocolo relativo tomado de usuarios; no existe autenticación/cookie de sesión de cliente implementada. No se observó la condición concreta de fuga descrita.
DoS de formatos: fechas/formato de números vienen de mocks/código; no hay plantillas o digitsInfo controlados por usuarios. Revalidar cuando exista API editable.

B. COMPILACIÓN/INSTALACIÓN — DOS PAQUETES CON SEVERIDAD NPM CRÍTICA
piscina 4.4.0: gadget de contaminación de prototipo/ejecución de worker. Exige condiciones previas controladas por atacante; no hay endpoint de worker Node público de esta app. Se ejecuta en build, por lo que un pipeline comprometido o entradas de build no confiables siguen siendo relevantes. No se ejecutó un exploit.
tar 6.2.1: avisos de extracción de archivos maliciosos y escapes de enlaces/rutas. No se extraen TAR subidos por clientes; el riesgo está en instalación, herramientas y cadena de suministro. Tampoco se declara inocuo para CI.
No confundir ausencia en runtime del navegador con ausencia de riesgo. Prioridad P1: revisión de pipeline/migración aprobada.

C. DESARROLLO Y RESTO DE HERRAMIENTAS
Vite/esbuild/webpack-dev-server y middleware: exposición condicional al usar servidores de desarrollo, abrir páginas maliciosas o procesar solicitudes no confiables. El frontend Vercel servido es estático; ng serve no es el servidor de producción. Aislar desarrollo y mantener la migración pendiente.
PostCSS, serialize-javascript, glob/minimatch/picomatch/ajv y herramientas temporales: riesgos de entradas de build no confiables, mapas, patrones o archivos; no son endpoints de Flask. Los paquetes contenedores heredan avisos de sus dependencias.
Ver detalle de cada advisory y fixAvailable en npm-audit-classification-36.json. Las versiones sugeridas por npm se guardan como datos, no como una recomendación de instalar automáticamente.

D. DEPENDENCIAS PYTHON — REVISIÓN DIRIGIDA, NO ESCANEO COMPLETO
No se instaló pip-audit ni se ejecutó un escáner exhaustivo de Python. requirements.txt permanece sin cambios.
Flask-Cors 4.0.1: defecto conocido relacionado con Access-Control-Allow-Private-Network por defecto. Se comprobó localmente que responde true a un preflight con ese encabezado. Los orígenes siguen restringidos; no se demostró bypass de la allowlist ni un ataque contra una red privada. Diagnóstico P1 para revisión de dependencia/configuración, sin corregir por la restricción de 3.6.
Werkzeug 3.1.3: GHSA-hgf8-39gv-g3f2 afecta safe_join en Windows con nombres de dispositivos especiales; la condición Windows no corresponde al backend Linux de Vercel ni al equipo macOS auditado. No extrapolar esta revisión dirigida a todos los avisos de Werkzeug/Flask.
